# Hucobu frontend

This folder contains the React frontend of Hucobu. It uses Create React App, TypeScript and Tailwind CSS.

For the full instructions, refer to the `README.md` file in the project root.

## Use

1. Install the dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm start
   ```

3. Open <http://localhost:3000> in your browser.

Make sure the backend runs on <http://localhost:3001>. To use a different backend URL, set `REACT_APP_API_URL` in `frontend/.env`.

To make a production build in the `build/` folder, use this command:

```bash
npm run build
```
